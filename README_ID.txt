KUOTALAB simulasi — PROYEK SUMBER APK
================================

Ini prototype independen, bukan aplikasi resmi Telkomsel. Semua paket dan fitur mod hanya simulasi lokal; tidak mengubah kuota operator dan tidak memintas proteksi jaringan.

CARA MEMBUAT APK:
1. Ekstrak ZIP.
2. Instal Android Studio di komputer.
3. Pilih Open, lalu pilih folder KuotaLabsimulasi hasil ekstrak.
4. Tunggu Gradle Sync selesai (internet mungkin dibutuhkan untuk mengunduh komponen).
5. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK debug biasanya muncul di app/build/outputs/apk/debug/app-debug.apk.

Catatan: File ZIP ini adalah source project Android, bukan APK yang sudah dikompilasi. Nama dan ikon simulasi dibuat berbeda dari aplikasi operator agar tidak menyamar sebagai aplikasi resmi.
